3.1.4 Solusi Cara Mengatasi Kendala (Tools Pendukung)

Untuk mengatasi kendala biaya dan batasan penggunaan pada tools AI Assistant, penulis menerapkan strategi efisiensi sebagai berikut:

1. Strategi Rotasi Akun dan Manajemen Langganan (Antigravity)
Guna menyiasati keterbatasan kredit dan biaya langganan pada Antigravity, penulis menggunakan metode rotasi akun Google. Langkah-langkahnya meliputi:
   - Memanfaatkan masa uji coba gratis (*free trial*) selama 1 bulan pada satu akun Google utama.
   - Memonitor penggunaan kredit secara berkala. Jika batas kredit mendekati habis atau masa uji coba akan berakhir, penulis segera membatalkan langganan (*cancel subscription*) untuk menghindari tagihan otomatis.
   - Beralih menggunakan akun Google alternatif untuk mendaftar layanan uji coba baru, sehingga akses ke fitur AI tetap terjaga tanpa mengeluarkan biaya tambahan.

2. Pemanfaatan Akses Edukasi (GitHub Copilot)
Sebagai solusi alternatif untuk biaya langganan GitHub Copilot, penulis memanfaatkan program GitHub Student Developer Pack. Akses ini diperoleh dengan cara membeli akun GitHub berstatus pelajar melalui platform *marketplace* (Shopee) dengan harga yang jauh lebih terjangkau dibandingkan biaya langganan reguler. Dengan akun tipe ini, penulis mendapatkan akses penuh ke GitHub Copilot secara gratis selama status pelajar aktif, yang sangat membantu efisiensi anggaran operasional magang.
