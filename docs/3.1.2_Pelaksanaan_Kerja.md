### 3.1.2. Pelaksanaan Kerja

Proses pelaksanaan kegiatan magang dilakukan dengan mengikuti metode pengembangan perangkat lunak yang sistematis untuk memastikan proyek Sistem Manajemen Ternak dapat diselesaikan dengan baik dan memenuhi standar yang ditetapkan oleh PT Microdata Indonesia. Tahapan pelaksanaan kerja yang dilakukan penulis meliputi lima tahap utama, yaitu analisis kebutuhan, perancangan sistem, implementasi program, pengujian, dan evaluasi.

1. Tahap Analisis Kebutuhan (Requirement Analysis)
Tahap awal pelaksanaan kerja dimulai dengan diskusi intensif bersama pembimbing lapangan dan tim pengembang. Fokus utama pada tahap ini adalah memahami spesifikasi fungsional yang dibutuhkan oleh sistem backend.

a. Identifikasi Kebutuhan Sistem
   Menganalisis kebutuhan API yang diperlukan oleh aplikasi mobile dan web, termasuk endpoint untuk autentikasi, manajemen data ternak, marketplace, dan fitur pendukung lainnya.

b. Penetapan Fitur Backend
   Menentukan modul-modul API prioritas yang akan dikembangkan, yaitu sistem autentikasi pengguna, manajemen hewan ternak, sistem pemesanan produk, integrasi layanan AI untuk deteksi penyakit, serta modul edukasi dan notifikasi.

c. Analisis Teknologi
   Memilih tech stack yang relevan untuk pengembangan backend, yaitu Node.js dengan framework Express.js untuk server, Cloud Firestore sebagai database, dan Firebase Authentication untuk sistem keamanan pengguna.

2. Tahap Perancangan Sistem (System Design)
Setelah kebutuhan teridentifikasi, penulis melanjutkan ke tahap perancangan arsitektur backend dan struktur data.

a. Perancangan Arsitektur API
   Merancang struktur folder proyek backend yang modular, terdiri dari direktori controllers, models, routes, middlewares, services, dan utils. Pendekatan ini memudahkan pengelolaan kode dan kolaborasi tim.

b. Desain Struktur Data
   Merancang skema data untuk setiap koleksi di Firestore, seperti struktur dokumen untuk User, Animal, Product, Order, Address, dan Notification. Setiap skema mempertimbangkan relasi antar data dan efisiensi query.

c. Perancangan Alur Proses
   Membuat diagram alur untuk proses bisnis utama, seperti alur registrasi dan login pengguna, proses penambahan data hewan, mekanisme pemesanan produk, serta alur komunikasi dengan layanan AI.

3. Tahap Implementasi (Development)
Tahap ini merupakan inti dari pelaksanaan kerja, di mana penulis menerjemahkan rancangan menjadi kode program yang fungsional.

a. Pengembangan Controller dan Routes
   Penulis membangun file-file controller (authController.js, farmController.js, marketplaceController.js, orderController.js, aiController.js, dan lainnya) yang berisi logika bisnis aplikasi. Setiap controller dihubungkan dengan routes yang mendefinisikan endpoint API.

b. Pengembangan Model Data
   Membuat file-file model (User.js, Animal.js, Product.js, Order.js, Address.js, dan lainnya) yang berisi metode untuk operasi database seperti create, getById, getAll, update, dan delete.

c. Implementasi Middleware
   Mengembangkan middleware untuk autentikasi token (verifikasi Firebase ID Token), penanganan error secara terpusat (error handling), dan validasi request dari client.

d. Integrasi Layanan Eksternal
   Menghubungkan backend dengan layanan Firebase (Authentication dan Firestore) serta layanan microservice Python untuk fitur deteksi penyakit berbasis AI.

4. Tahap Pengujian (Testing)
Untuk menjamin kualitas dan keandalan API, penulis melakukan serangkaian pengujian:

a. Pengujian Endpoint API
   Melakukan pengujian setiap endpoint menggunakan tools seperti Postman untuk memastikan response yang dikembalikan sesuai dengan spesifikasi (status code, format JSON, data yang benar).

b. Pengujian Autentikasi dan Otorisasi
   Memastikan sistem keamanan berfungsi dengan baik, yaitu hanya pengguna yang memiliki token valid yang dapat mengakses endpoint terproteksi, serta pengguna hanya dapat mengakses data miliknya sendiri.

c. Pengujian Integrasi
   Menguji komunikasi antara backend dengan layanan Firebase dan microservice AI untuk memastikan data dapat dipertukarkan dengan benar tanpa error.

5. Tahap Evaluasi dan Dokumentasi
Pada tahap akhir, penulis melakukan pelaporan hasil kerja kepada pembimbing.

a. Code Review
   Melakukan tinjauan kode bersama mentor untuk mendapatkan masukan terkait efisiensi kode, struktur program, dan best practices dalam pengembangan backend.

b. Dokumentasi API
   Menyusun dokumentasi teknis yang menjelaskan setiap endpoint API, termasuk URL, metode HTTP, parameter yang diperlukan, dan contoh response.

c. Penyusunan Laporan
   Menyusun laporan progres kerja harian (logbook) sebagai pertanggungjawaban kegiatan magang.
