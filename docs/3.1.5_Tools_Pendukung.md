3.1.1 Penggunaan Tools Pendukung Pengembangan (AI Assistant)

Dalam proses pengembangan Sistem Manajemen Ternak, penulis memanfaatkan dua asisten pemrograman berbasis kecerdasan buatan (AI Coding Assistant) utama, yaitu Antigravity dari Google dan GitHub Copilot. Kedua tools ini digunakan secara terintegrasi di dalam lingkungan pengembangan (IDE) untuk meningkatkan produktivitas, kualitas kode, dan efisiensi penyelesaian masalah. Berikut adalah rincian spesifikasi, fungsi, serta cara instalasi dan penggunaan masing-masing alat tersebut.

A. Antigravity (Google AI Coding Assistant)

Antigravity adalah agen AI canggih yang dikembangkan oleh Google DeepMind, dirancang untuk menjadi mitra pair programming digital yang cerdas dan interaktif. Alat ini memiliki kemampuan pemahaman konteks proyek yang mendalam, memungkinkan pengembang untuk berdiskusi, merancang solusi, dan melakukan perbaikan kode secara komprehensif.

1. Spesifikasi dan Fitur Utama
   - Model Dasar (Foundation Model): Menggunakan Large Language Model (LLM) mutakhir, seperti Gemini, yang dilatih khusus pada korpus kode sumber raksasa.
   - Context Awareness: Mampu membaca dan memahami seluruh struktur kode proyek yang sedang dibuka, bukan hanya file aktif.
   - Chat Interface: Menyediakan antarmuka percakapan (chat) di dalam IDE untuk tanya-jawab teknis, debugging, dan refactoring kode.
   - Smart Actions: Dapat melakukan tindakan langsung seperti menulis kode baru, memperbaiki bug, menambahkan komentar, hingga menjalankan perintah terminal.

2. Cara Instalasi dan Konfigurasi
   - Persiapan: Pastikan menggunakan Visual Studio Code (VS Code) versi terbaru atau mengakses platform cloud IDE Google (seperti Project IDX).
   - Instalasi Ekstensi: Buka Marketplace ekstensi di VS Code, cari ekstensi resmi Google (misalnya: "Google Cloud Code" atau "Gemini Code Assist"), lalu klik tombol "Install".
   - Login Akun Google: Setelah terinstal, lakukan sign-in menggunakan akun Google yang memiliki akses atau lisensi untuk layanan AI tersebut.

3. Cara Penggunaan
   - Interaksi Chat: Buka panel chat Antigravity (biasanya dengan pintasan Ctrl + I atau klik ikon di sidebar). Ketikkan instruksi dalam bahasa alami, contoh: "Buatkan struktur controller untuk manajemen data hewan ternak (CRUD) menggunakan Firebase Firestore."
   - Penerapan Kode: Tinjau solusi yang diberikan oleh AI, lalu pilih opsi "Insert" atau "Apply" untuk memasukkan kode tersebut secara otomatis ke dalam editor.

B. GitHub Copilot

GitHub Copilot, yang dikembangkan oleh GitHub (Microsoft) bekerja sama dengan OpenAI, berfungsi sebagai asisten penyelesaian kode (autocomplete) cerdas. Alat ini berfokus pada prediksi baris kode berikutnya secara real-time saat pengembang sedang mengetik, memberikan saran sintaks yang akurat dan efisien.

1. Spesifikasi dan Fitur Utama
   - Model Dasar: Ditenagai oleh OpenAI Codex, sistem AI yang mampu menerjemahkan bahasa alami menjadi kode.
   - Autocompletion & Suggestion: Memberikan saran kelanjutan kode (satu baris atau satu blok fungsi penuh) secara otomatis saat pengguna mengetik, berdasarkan pola kode sebelumnya.
   - Multi-Language Support: Mendukung puluhan bahasa pemrograman populer seperti JavaScript, TypeScript, Python, Go, dll.
   - Comment-to-Code: Mampu mengubah komentar deskriptif menjadi implementasi kode fungsional.

2. Cara Instalasi dan Konfigurasi
   - Syarat Akun: Memiliki akun GitHub yang aktif dan berlangganan layanan GitHub Copilot (atau menggunakan akses Student Developer Pack gratis bagi mahasiswa).
   - Instalasi Ekstensi: Buka VS Code, masuk ke menu "Extensions", cari "GitHub Copilot", dan klik "Install".
   - Login GitHub: Setelah instalasi selesai, akan muncul notifikasi untuk login. Lakukan autorisasi akun GitHub melalui browser.

3. Cara Penggunaan
   - Penulisan Kode: Mulailah mengetik kode seperti biasa di editor. Copilot akan secara otomatis menampilkan saran kode berwarna abu-abu (ghost text).
   - Menerima Saran: Tekan tombol Tab untuk menerima saran kode tersebut sepenuhnya.
   - Navigasi Opsi: Jika saran pertama kurang sesuai, tekan Alt + [ atau Alt + ] untuk melihat alternatif saran lainnya.
   - Komentar Instruksi: Tulis komentar seperti // Fungsi untuk menghitung total harga pesanan, dan Copilot akan menyarankan blok kode fungsi di bawahnya.

Penggunaan kedua alat ini secara bersamaan memberikan sinergi yang optimal bagi penulis. GitHub Copilot mempercepat penulisan sintaks sehari-hari melalui fitur autocomplete, sementara Antigravity membantu dalam pemecahan masalah kompleks, desain arsitektur, dan penjelasan logika program melalui fitur percakapan interaktifnya.
