### 3.1.3. Kendala yang Dihadapi

Selama proses pengembangan backend untuk proyek Sistem Manajemen Ternak di PT Microdata Indonesia, penulis menghadapi beberapa kendala teknis yang mempengaruhi alur kerja. Kendala-kendala utama yang diidentifikasi adalah sebagai berikut:

1. Kompleksitas Integrasi Firebase Authentication dengan Backend
Menghubungkan sistem autentikasi Firebase dengan backend Node.js memerlukan pemahaman mendalam tentang mekanisme token.

Masalah: Pada tahap awal, terjadi kesulitan dalam memverifikasi Firebase ID Token yang dikirim oleh aplikasi client. Proses verifikasi sering mengalami kegagalan karena kesalahan konfigurasi service account dan perbedaan format token yang diterima dari aplikasi mobile dan web.

2. Pengelolaan Struktur Data NoSQL di Cloud Firestore
Cloud Firestore menggunakan pendekatan NoSQL yang berbeda dengan database relasional tradisional.

Masalah: Penulis mengalami kesulitan dalam merancang struktur data yang efisien untuk relasi antar koleksi, seperti relasi antara Order dengan Product dan User. Query yang kompleks untuk mengambil data dari beberapa koleksi sekaligus memerlukan pendekatan yang berbeda dari SQL biasa, sehingga beberapa fitur awalnya berjalan lambat.

3. Penanganan Error dan Response yang Konsisten
Membangun API yang melayani banyak endpoint memerlukan standarisasi penanganan error.

Masalah: Pada awal pengembangan, format response error dari setiap endpoint tidak konsisten. Hal ini menyulitkan tim frontend dalam menangani error di sisi aplikasi client karena struktur pesan error berbeda-beda antara satu endpoint dengan yang lain.

4. Sinkronisasi Data Real-time untuk Fitur Notifikasi
Sistem notifikasi memerlukan mekanisme yang dapat mengirimkan data secara real-time ke aplikasi client.

Masalah: Implementasi fitur notifikasi awalnya hanya menggunakan pendekatan polling (client meminta data secara berkala), yang menyebabkan keterlambatan dalam pengiriman notifikasi dan meningkatkan beban server karena request yang berulang.

5. Integrasi dengan Microservice AI (Python)
Backend Node.js harus berkomunikasi dengan layanan terpisah berbasis Python untuk fitur deteksi penyakit.

Masalah: Terjadi kendala dalam pengiriman data gambar berukuran besar dari backend ke microservice Python. Proses encoding dan decoding gambar memakan waktu lama, dan sering terjadi timeout ketika ukuran gambar melebihi batas tertentu.
