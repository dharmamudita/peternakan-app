### 3.1.1. Bidang Kerja

Pelaksanaan kegiatan Magang oleh Dharma Mudita (NPM 23311067) dilaksanakan di Divisi Pengembangan Aplikasi PT Microdata Indonesia, di bawah bimbingan Bapak Sigit Wasis Subekti selaku Programmer. Selama masa pelaksanaan, penulis terlibat secara aktif dalam pengembangan proyek Sistem Manajemen Ternak, yaitu sebuah aplikasi berbasis mobile dan web yang dirancang untuk membantu peternak dalam mengelola data hewan, memantau kesehatan ternak, serta melakukan transaksi jual-beli hasil peternakan secara digital. Pada proyek ini, penulis berperan sebagai Backend Developer yang bertanggung jawab atas pembangunan sisi server (server-side), pengelolaan basis data, serta penyediaan Application Programming Interface (API) yang menghubungkan aplikasi mobile maupun web dengan sistem. Berikut adalah rincian tugas yang dilaksanakan selama kegiatan magang:

1. Pengembangan Arsitektur Backend dan RESTful API
Penulis bertugas membangun fondasi backend aplikasi menggunakan teknologi Node.js dengan framework Express.js. Fokus utama adalah merancang dan mengimplementasikan arsitektur API yang terstruktur dan modular agar dapat melayani permintaan dari aplikasi mobile (React Native) maupun aplikasi web. Rincian tugas meliputi:

a. Pembuatan Modul API Autentikasi (Authentication)
   Mengembangkan endpoint API untuk proses registrasi, login, dan verifikasi token pengguna. Sistem autentikasi diintegrasikan dengan layanan Firebase Authentication untuk memastikan keamanan akses data pengguna baik dari perangkat mobile maupun browser.

b. Pengembangan API Manajemen Ternak (Livestock Management)
   Membuat controller dan routes untuk fitur pengelolaan data hewan ternak, termasuk operasi CRUD (Create, Read, Update, Delete) untuk data hewan, pencatatan riwayat kesehatan (Health Records), serta statistik peternakan yang dapat diakses melalui dashboard.

c. Pengembangan API Marketplace dan Pemesanan
   Membangun sistem backend untuk modul jual-beli produk ternak, meliputi manajemen produk, keranjang belanja (Cart), sistem pemesanan (Order), dan profil toko penjual (Shop).

2. Pemodelan Data dan Integrasi Database
Penulis bertanggung jawab dalam merancang struktur data dan menghubungkan aplikasi dengan layanan basis data Cloud Firestore dari Google Firebase.

a. Perancangan Model Data
   Membuat skema model data untuk berbagai entitas aplikasi seperti User, Animal, Product, Order, Course, Address, dan Notification. Setiap model dilengkapi dengan metode-metode untuk operasi query dan manipulasi data.

b. Implementasi Relasi Antar Data
   Merancang logika bisnis yang menghubungkan data antar koleksi, seperti relasi antara pengguna dengan alamat pengiriman, produk dengan toko penjual, serta pesanan dengan detail itemnya.

3. Integrasi Layanan Kecerdasan Buatan (AI)
Salah satu tugas penting adalah menyediakan endpoint API yang menjembatani aplikasi client (baik mobile maupun web) dengan layanan Machine Learning untuk deteksi penyakit ternak.

a. Pengembangan AI Controller
   Membuat controller (aiController.js) yang bertugas menerima data gambar dari aplikasi pengguna, meneruskannya ke layanan microservice Python untuk dianalisis, lalu mengembalikan hasil diagnosis (jenis penyakit, tingkat keparahan, dan rekomendasi penanganan) ke aplikasi.

4. Pengembangan Fitur Pendukung Sistem
Selain modul utama, penulis juga mengembangkan fitur-fitur pendukung untuk melengkapi fungsionalitas sistem:

a. Sistem Notifikasi
   Membangun API untuk mengelola notifikasi pengguna, termasuk fitur tandai sudah dibaca (mark as read) dan pengambilan daftar notifikasi berdasarkan pengguna.

b. Manajemen Alamat Pengiriman
   Mengembangkan fitur lengkap untuk pengelolaan alamat pengiriman pengguna, termasuk menambah, mengubah, menghapus, dan menetapkan alamat utama (default address).

c. Modul Edukasi dan Statistik
   Menyediakan endpoint untuk modul kursus/edukasi peternak serta API statistik yang menyajikan ringkasan data peternakan pada dashboard pengguna.

Melalui peran sebagai Backend Developer pada proyek Sistem Manajemen Ternak, penulis memperoleh pengalaman mendalam mengenai siklus pengembangan server-side application, perancangan arsitektur API yang baik untuk mendukung aplikasi multi-platform (mobile dan web), serta penerapan integrasi layanan cloud dan kecerdasan buatan dalam memecahkan masalah nyata di industri peternakan.
