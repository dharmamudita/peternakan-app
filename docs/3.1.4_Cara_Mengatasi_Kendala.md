### 3.1.4. Cara Mengatasi Kendala

Berdasarkan kendala-kendala yang telah diuraikan sebelumnya, penulis melakukan berbagai upaya analisis dan perbaikan teknis untuk memastikan sistem backend dapat berjalan dengan optimal. Berikut adalah solusi yang diterapkan untuk menyelesaikan setiap kendala:

1. Perbaikan Konfigurasi Firebase dan Middleware Autentikasi
Untuk mengatasi kendala integrasi Firebase Authentication dengan backend:

Penyelesaian: Penulis melakukan konfigurasi ulang service account Firebase dengan mengunduh file kredensial JSON yang benar dan menempatkannya di direktori config. Selain itu, penulis mengembangkan middleware authMiddleware.js yang secara khusus menangani verifikasi token dari berbagai sumber (mobile dan web) dengan memvalidasi format token sebelum proses verifikasi dilakukan.

2. Optimasi Struktur Data dan Query Firestore
Untuk mengatasi kesulitan pengelolaan data NoSQL:

Penyelesaian: Penulis mempelajari dokumentasi resmi Firestore dan menerapkan teknik denormalisasi data, yaitu menyimpan sebagian data yang sering diakses bersama dalam satu dokumen untuk mengurangi jumlah query. Selain itu, penulis mengimplementasikan metode populateRelations pada setiap model untuk mengambil data terkait secara efisien menggunakan Promise.all().

3. Standarisasi Response Helper
Untuk mengatasi inkonsistensi format response API:

Penyelesaian: Penulis membuat file utils/responseHelper.js yang berisi fungsi-fungsi standar untuk mengirimkan response, seperti success(), created(), badRequest(), notFound(), dan forbidden(). Seluruh controller kemudian diperbarui untuk menggunakan fungsi-fungsi ini, sehingga format response menjadi konsisten di seluruh endpoint API.

4. Implementasi Mekanisme Polling yang Efisien
Untuk mengatasi keterlambatan fitur notifikasi:

Penyelesaian: Penulis mengoptimalkan endpoint notifikasi dengan menambahkan parameter filter (seperti status isRead) dan pagination untuk mengurangi jumlah data yang ditransfer. Selain itu, penulis mengimplementasikan mekanisme caching sederhana di sisi client yang dikoordinasikan dengan tim frontend, sehingga request polling tidak membebani server secara berlebihan.

5. Kompresi dan Optimasi Transfer Data Gambar
Untuk mengatasi timeout pada integrasi dengan microservice AI:

Penyelesaian: Penulis mengimplementasikan proses kompresi gambar di sisi backend sebelum data dikirim ke microservice Python. Gambar dikonversi ke format Base64 dengan resolusi yang lebih kecil tanpa mengurangi kualitas fitur diagnostik. Selain itu, penulis menambahkan konfigurasi timeout yang lebih panjang dan mekanisme retry otomatis jika request pertama gagal, sehingga proses analisis penyakit dapat berjalan dengan lancar.

Melalui langkah-langkah penyelesaian tersebut, seluruh kendala utama dalam pengembangan backend berhasil diatasi. Sistem API dapat berfungsi dengan baik dan siap melayani permintaan dari aplikasi mobile maupun web.
